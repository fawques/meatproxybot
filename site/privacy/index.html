Privacy Policy

Last updated: 2024-10-03

This privacy policy ("Policy") describes what data Meatproxy collects, how we use it, how long we keep it, and your rights. If you have questions about this policy, please contact us at SUPPORT_EMAIL.

1. What Data Is Collected

1.1 Audit Log

Every time the bot is triggered, we write one audit log line recording:

  • event: Always "callout"
  • trigger: The trigger type (reaction, shortcut, or command)
  • invoker: The Slack user ID of the person who triggered the bot
  • channel: The Slack channel ID where the callout occurred
  • ts: The timestamp of the target message
  • poster: The Slack user ID of the message author (or null for system messages)
  • status: Whether the callout was posted, already posted, or encountered an error
  • reason: If status is "error", the reason (dm, own_message, not_in_channel, not_found, or unknown)

What is not logged: We never log message text, user tokens, or any other sensitive content. We do not log request IP addresses or HTTP access logs.

1.2 Installation Data

When you install Meatproxy, we store the following information in our database:

  • team.id: Your Slack workspace ID
  • enterprise.id: Your enterprise ID (if your workspace is part of an enterprise grid)
  • bot.id: The Slack app's bot user ID in your workspace
  • bot.token: A Slack bot token encrypted with AES-256-GCM
  • bot_user_id: The app's user ID in your workspace
  • app_id: The Slack app ID (same across all workspaces)
  • created_at: The timestamp when the app was installed
  • updated_at: The timestamp of the most recent reinstall

2. How Data Is Used

We use this data for the following purposes:

  • Running the bot: Installation data allows us to post messages to your workspace. Audit logs help us detect and fix bugs.
  • Detecting misuse: Audit logs help us identify users who are abusing the bot (e.g., systematically harassing others). If we detect misuse, we may share the invoker's ID with your workspace's Owners and Admins on a written request, or when legally required.

Who can see the invoker: The invoker's identity is never posted in Slack and is never shared with the person who posted the message or other workspace members. Only workspace Owners and Admins may request this information in writing, and only for documented misuse. We also disclose it when required by law.

3. Legal Basis (GDPR)

  • Installation data: We process this under the contract you create by installing the app.
  • Audit logs: We process this based on our legitimate interest in detecting and preventing abuse and understanding how the bot is used.

4. Data Retention

  • Audit logs: All audit logs (including the above, plus any future logs) are kept for no more than 30 days and are not edited one by one before deletion. Access logs, if added in the future, will also be kept for no more than 30 days.
  • Installation data: Installation data is stored in our database as long as the app is installed. When you uninstall the app or request data deletion, we remove it immediately from the live database and from all backups within 7 days.

5. Where Data Is Stored

All data is stored on a secure server. We protect your data using TLS 1.2+ for in-transit encryption and AES-256-GCM for bot token encryption at rest. Your data may also be processed by Slack and GitHub, which handle it according to their data processing agreements. These transfers rely on standard contractual clauses (EU SCCs) and/or adequacy decisions where applicable.

6. Subprocessors

The following subprocessors may handle your data:

  • GitHub (US): Hosts the static website. GitHub may log visitor IP addresses as its hosting platform.
  • Slack (US): Receives messages, reactions, and user information as part of app execution.

7. Website and Cookies

This website has no analytics, no third-party tracking, and no cookies. GitHub may log visitor IP addresses as the hosting platform. The OAuth installation flow uses one strictly necessary, short-lived state cookie to prevent forgery attacks. The bot's host keeps no request or IP logs.

8. Your Rights

Under GDPR and similar laws, you have the right to:

  • Access: Request a copy of all data we hold about your workspace.
  • Rectification: Request that we correct inaccurate data.
  • Deletion: Request that we delete your data (by uninstalling the app or submitting a data request).
  • Portability: Request that we provide your data in a structured, portable format.
  • Restriction: Request that we limit how we use your data.
  • Objection: Object to how we use your data (e.g., for abuse detection).
  • Automated decision-making: Request human review of automated decisions.

To exercise any of these rights, or to request deletion of your data, contact us at SUPPORT_EMAIL. We will respond within one month. If you believe your rights have been violated, you also have the right to lodge a complaint with the supervisory authority in CONTROLLER_COUNTRY.
